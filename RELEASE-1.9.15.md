# Tvim 1.9.15 — TVIM Message Screens

- The scheduled greeting mode is now named TVIM.
- Separate morning and evening message screens, with one card and editor per message. Add or delete messages individually.
- Time selection uses the same component and colors as the alarm screen, including Nothing typography. Choose a clock dial or numeric entry.
- Random selection, custom messages and saved schedules are preserved.

Install over the existing app to preserve data.
