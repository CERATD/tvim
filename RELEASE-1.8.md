# Tvim 1.8 — обновления внутри приложения

- Новая версия скачивается прямо из Tvim, без перехода в браузер или на GitHub.
- Фоновая загрузка через Android: процент выполнения, ожидание сети, повторная попытка и удаление загрузки.
- После завершения появляется уведомление с переходом к установке.
- Перед установкой проверяются целостность файла, приложение, версия и подпись APK.
- Установка запускается кнопкой «Установить» и подтверждается в Android. При первом запуске установки система может запросить разрешение для Tvim.

Версию 1.8 нужно один раз установить по ссылке APK. Начиная с неё следующие обновления скачиваются внутри приложения. Устанавливайте поверх ранее выданной 1.7, не удаляя приложение: ключ подписи сохранён.

Секундомер, таймер, библиотека импортированных мелодий и десять встроенных звуков из 1.7 сохранены.

Результаты автоматических проверок и ограничения: VERIFICATION.md. Проверка на физическом телефоне не выполнялась.
