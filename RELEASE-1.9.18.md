# Tvim 1.9.18 — Typing and Timer Improvements

- Moved the typing reference down, added explicit keyboard resize handling, and kept the reference outside the input scroll area.
- Russian typing challenges randomly choose from 13,440 short passages covering the supplied first-part book archive, without immediately repeating the last passage.
- Stopwatch controls and navigation use the same selected accent as the timer.
- Timer end sound is selectable from built-in or imported sounds, with preview. The choice is saved, and a running timer keeps its sound through pause/resume and recreation.

Install over the existing app to preserve data.
