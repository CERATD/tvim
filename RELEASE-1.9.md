# Tvim 1.9 — Nothing Design and refreshed icons

- Added an optional Nothing Design setting. The mode applies monospaced typography, dotted iconography, switches and progress rings, with a consistent red accent; it can be turned off at any time.
- Replaced the launcher icon with the red-and-black logo image supplied by the user, including adaptive Android icons.
- Kept the alarm, stopwatch, timer, custom sounds, and in-app update flow.

Install over the existing Tvim version without uninstalling to preserve alarms and settings. The release APK uses the same signing certificate as the previous versions.
