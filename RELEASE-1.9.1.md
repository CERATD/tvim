# Tvim 1.9.1 — Nothing typography

- Restored standard Android switches in both appearance modes.
- Added Doto's dot-matrix typeface for alarm, timer, stopwatch and mission numbers while Nothing Design is active.
- Updated interface text to a more readable, letter-spaced sans-serif style that supports Russian and English.

Install over Tvim 1.9 without uninstalling to keep alarms, settings and imported sounds.
