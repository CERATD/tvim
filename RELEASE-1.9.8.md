# Tvim 1.9.8 — Monochrome Stopwatch

The stopwatch is now monochrome throughout Nothing Design. Lap times no longer use red or green speed highlighting, the stopwatch controls use neutral black, gray and white, and the selected stopwatch tab stays white. The user's chosen accent color continues to apply to alarms, the timer and settings.

The centered digital time separators from 1.9.7 remain in the alarm, timer and stopwatch screens.

Install over the previous version. The application ID and signing certificate are unchanged.
